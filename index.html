rclone – client OAuth personale

Questo client OAuth è usato da una sola persona, il proprietario dell'account, per caricare file sul proprio Google Drive con rclone, software open source non modificato.

Privacy

  • L'app accede solo ai file che crea lei stessa (scope drive.file).
  • Nessun dato viene raccolto, condiviso con terzi o inviato a server diversi da Google.
  • Le credenziali restano salvate solo sul computer del proprietario.
  • Non è un servizio pubblico: nessun altro utente la usa.

Contatti: tramite l'email di assistenza indicata nella schermata di consenso Google.
